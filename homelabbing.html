STACK & SERVICES

What's running on the machine

Using Oracle VirtualBox to run virtual machines on top of the laptop, bridged with Tailscale to provide a permanent static IP for secure remote access.

🗄️

OpenMediaVault (OMV)

NETWORK ATTACHED STORAGE (NAS)

Debian-based NAS solution running in an Oracle VirtualBox VM. Manages storage partitions, user shares, SMB/CIFS network folders, and provides centralized file access across all devices on the home network.

NAS System Debian VM SMB / CIFS Shares Storage Management
🎬

Plex Media Server

PERSONAL STREAMING HUB

My personal Netflix alternative. Catalogs movies, shows, and downloaded media stored on the 1TB hard drive and streams them in high quality to smartphones, laptops, and TV on the local network without subscriptions.

Plex Media Direct Stream Local LAN Zero Subscriptions
🔒

Tailscale Mesh Network

DYNAMIC-TO-STATIC IP & REMOTE ACCESS

Home ISPs constantly change public IP addresses, which breaks remote connections. Tailscale solves this by creating a secure WireGuard mesh that converts my changing IP into a permanent, static private IP (MagicDNS). Lets me securely access OMV files and stream Plex from anywhere outside home without opening risky router ports or dealing with CGNAT.

Tailscale Static Private IP WireGuard Mesh Zero Port Forwarding Remote Streaming
📦

Oracle VirtualBox

TYPE-2 HYPERVISOR

Hosts the virtual machines with dedicated CPU core allocation and memory limits. Uses bridged network adapters so OMV and services get their own distinct local IP addresses directly from the router.

Hypervisor Bridged Adapter Resource Limiting
THE PHILOSOPHY

Not a proper home lab, but a start.

You don't need a thousand-dollar server rack or enterprise equipment to start a home lab. A real homelab is about taking whatever hardware you have and building something useful with it.

My old Dell Inspiron P51F laptop (12GB RAM, 1TB storage) was sitting idle. Instead of letting it gather dust, I turned it into a quiet, power-efficient, 24/7 home server. One great hidden superpower of a laptop server: the laptop battery acts as a built-in UPS during brief power flickers!

Running OpenMediaVault and Plex inside Oracle VirtualBox, backed by Tailscale to convert my changing dynamic IP into a rock-solid static private IP, has taught me practical lessons on virtualization, mesh networking, storage pools, and Linux systems. It's not a proper enterprise homelab yet, but it solves my everyday storage & streaming needs — and I will scale this over time.
